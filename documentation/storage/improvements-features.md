# Storage — Features Improvements

## 1. Managed external sharing links with expiration controls

Add owner-managed, expiring links with viewer/download modes so teams can share files outside their group without adding external users as platform accounts. The existing public Firebase download URL is a bearer URL without app-managed expiration or revocation controls; the private signed-URL callable is for authorized members and is not an external-share workflow.

## 2. Folder and tag organization

Introduce lightweight folders/tags plus filter chips to make high-volume file libraries easier to navigate and to support app-specific filing conventions.

## 3. File version history

Allow owners to upload new versions of an existing file record while preserving prior revisions and changelog metadata. This supports document workflows without duplicate clutter.

## 4. Storage analytics dashboard

Extend the current per-user/group totals card with trends (growth by week/month, top contributors, largest files, stale files) so admins can manage retention and cost proactively.
