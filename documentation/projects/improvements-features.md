# Projects — Feature Improvements

- P1 | **Project templates and reusable blocker trees are missing** | Teams that run similar projects must recreate the same structure manually every time. | Add reusable project templates that can prefill project metadata plus nested blocker tasks.

- P1 | **No history, comments, or activity feed exists** | Collaborators cannot easily see who changed status, added blockers, or edited the plan. | Add project/task activity history with optional comments and lightweight audit metadata.

- P2 | **Actionability supports only the current direct-child model** | Some teams may want stricter dependency semantics or alternative planning views. | Add optional planning modes such as strict descendant readiness, Kanban-style task grouping, or milestone views.

- P2 | **Projects have no reminders or due-date nudges** | Due dates exist, but the feature does not proactively help teams stay on schedule. | Add configurable reminders for approaching due dates, stale blockers, and newly unblocked high-priority work.

- P2 | **Attachment files have no in-app preview for non-image types** | PDFs, spreadsheets, and documents open in an external app or browser via a chip link. | Add an in-app document preview (using a WebView or a native document viewer plugin) for common formats such as PDF and plain text to keep context inside the app.

- P3 | **No bulk attachment management** | Attachments must be added or removed one form-open at a time; there is no gallery or media-browser view across all tasks in a project. | Add a project-level media gallery that lists all attachments from all tasks, allowing bulk review, download, or deletion.
